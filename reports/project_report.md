# 大数据技术课程项目报告

## 项目标题

MovieLens 分布式增量电影推荐系统

## 一、问题定义

### 1.1 背景

推荐系统是互联网平台的核心技术之一，需要同时解决海量行为数据处理、用户兴趣建模、候选召回、结果排序和在线更新等挑战。

### 1.2 目标

- 核心指标：Top 10 推荐的 NDCG@10 相对热门推荐基线提高 >= 10%
- 次要指标：Recall@10、数据处理吞吐量、单用户推荐延迟
- 可复现性：教师使用提交的代码和配置文件能重新运行出结果

## 二、算法设计

### 2.1 召回策略

| 方法 | 原理 | 复杂度 |
|------|------|--------|
| UserCF | 用户相似度 + 近邻推荐 | O(U^2 * I) |
| ItemCF | 物品相似度 + 历史交互 | O(I^2 * U) |
| LSH | 局部敏感哈希近似检索 | O(U * log U) |

### 2.2 排序策略

- ALS 矩阵分解 (Spark MLlib)
- 图特征增强 (PageRank / 社区发现)

### 2.3 增量更新

- 滑动窗口统计
- 用户画像增量更新

## 三、系统架构

```
[数据层] 原始数据 -> 清洗 -> 划分 -> 特征工程
    |
[算法层] 召回 (多路) -> 排序 (精排) -> Top-K
    |
[服务层] 推荐结果输出 + 模型版本管理
    |
[实验层] 参数管理 + 日志 + 指标对比
```

## 四、实验设置

### 4.1 数据集

- MovieLens 32M
- 正反馈定义：评分 >= 4
- 时间划分：80% 训练 / 10% 验证 / 10% 测试

### 4.2 环境

- OS: Windows 11
- Python: 3.10+
- Spark: PySpark 3.5+
- 内存: 16GB+

### 4.3 参数

见 config.yaml
